# 🛍️ Ecommerce Web App

A **modern**, **responsive** eCommerce web application built with **React** and **Tailwind CSS**.  
Showcasing products for men, women, and kids with a clean design and smooth user experience.

---

## ✨ Features

- ⚡ Responsive design with Tailwind CSS  
- 🛒 Product listings for multiple categories  
- 🧩 Shopping cart powered by React Context API  
- 🔥 Modern React hooks & functional components  
- 🚀 Fast build system using Vite  
- 📦 Easy deployment on GitHub Pages
